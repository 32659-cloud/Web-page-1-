# 需求說明

## 這是什麼
一個不用登入的匿名聊天室。所有人在同一個公開聊天室裡,也可以邀請某個人私聊,對方同意後才開始。

## 誰會用
任何知道網站連結的人都可以進來用,可以用電腦,也可以用手機。

## 使用的流程
1. 打開網頁
2. 輸入一個代號,同時選擇介面語言(繁體中文、English、日本語、한국어、Español、Français)
3. 進入公開聊天室,看到其他人的訊息,也可以送出訊息
4. 可以傳送照片
5. 在線上名單點某個人,按「邀請私聊」
6. 對方會看到邀請,按「接受」或「拒絕」
   - 接受:雙方開啟一個只有兩個人的私聊視窗
   - 拒絕:邀請者看到「對方拒絕了」,不能開始聊天
7. 私聊中也可以傳訊息與照片,任何一方都可以結束私聊

## 畫面上要有
- 誰在線上(名單與人數)
- 有人進來或離開時要有提示
- 邀請私聊的通知,有「接受」「拒絕」兩個按鈕
- 公開聊天與私聊的切換,有新訊息的私聊要有未讀提示
- 傳照片的按鈕,照片在對話裡直接看到縮圖,點開可放大
- 連線狀態(已連線 / 重新連線中)
- 手機版也要好用

## 新增功能
- **私聊與對方確認**:要對方按「接受」才能開始,可以拒絕,也可以隨時結束
- **傳送照片**:公開聊天與私聊都能傳,使用 Supabase Storage(檔案儲存服務)
- **多語言介面**:輸入代號時選語言,按鈕、提示、系統訊息都用該語言顯示;預設依瀏覽器語言,進入後也能切換。使用者打的聊天內容不翻譯

## 規則(我的決定,你可以改)
- 照片限 JPG、PNG、WebP,大小上限 2 MB,送出前先在瀏覽器壓縮縮小
- 私聊的訊息與照片,只有兩個參與者看得到
- 被拒絕後,同一個人 30 分鐘內不能對同一對象再邀請(避免騷擾)
- 私聊只保存在本次連線,不永久保存;公開聊天只保留最近 100 則

## 不需要的
- 註冊、登入
- 多人私聊群組
- 影片、檔案傳送
- 永久保存所有訊息
