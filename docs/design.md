## 2. 風格

- **感覺**:簡潔、明亮、圓角,像一般通訊軟體。自己的訊息靠右、別人的靠左。
- **顏色**:薰衣草紫、淺粉紅、水藍色三個色系(你指定的)。淺色模式黑字,深色模式白字,深色是同三色系的暗色版。
- **深色模式**:預設跟隨系統,可手動切換,下次進來記住(行為見 `architecture.md` 7.1)。
- **圖示**:全部是線條圖示(stroke 2px、圓角端點),不使用 emoji 當介面圖示。
- **字體**:Noto Sans TC(Google Fonts),後備 `system-ui`;日文、韓文用系統字體補上。字級見第 4 節。
- **頭像**:沒有大頭貼。用代號的第一個字放在圓形裡,底色由代號計算出固定的一個顏色(見 3.3)。

## 3. 顏色

### 3.1 顏色變數(兩種模式的值)

| 變數 | 用途 | 淺色 | 深色 |
|---|---|---|---|
| `--bg` | 整個頁面背景 | `#F6F2FC` | `#14111E` |
| `--surface` | 卡片、欄位、頂部列 | `#FFFFFF` | `#1D1929` |
| `--surface2` | 輸入框底、次要區塊、系統提示底 | `#EFE9FA` | `#2A2440` |
| `--line` | 分隔線、邊框 | `#E2DAF2` | `#3A3354` |
| `--text` | 主要文字 | `#1A1625` | `#F5F2FB` |
| `--muted` | 次要文字(時間、說明) | `#625C78` | `#B5ADCB` |
| `--lav` | 薰衣草(淺):選中的列、標籤 | `#CDBDF4` | `#4B3C86` |
| `--lavS` | 薰衣草(深):主要按鈕、邀請卡片邊框 | `#B9A3EC` | `#8B72DB` |
| `--pink` | 淺粉紅:離開、結束私聊、錯誤提示的底 | `#FAD3E1` | `#6B3151` |
| `--pinkS` | 淺粉紅(深):危險動作按鈕、錯誤邊框 | `#F4A9C5` | `#E07BA6` |
| `--blue` | 水藍(淺):已連線標籤、對方的泡泡、傳照片鈕 | `#D3EEF9` | `#244E63` |
| `--blueS` | 水藍(深):線上圓點、載入條 | `#8FD0EC` | `#58B3DA` |
| `--own` | 自己的訊息泡泡 | `#DCCFF8` | `#54428F` |
| `--peer` | 對方的訊息泡泡 | `#DDF1FA` | `#25475A` |
| `--badge` | 未讀數字的底 | `#F29BBB` | `#F29BBB` |
| `--onS` | 放在「深」色塊上的文字 | `#1A1625` | `#14111E` |
| `--errText` | 錯誤文字(只在需要時用) | `#A12B58` | `#F4A9C5` |

- 未讀紅點用的是**粉紅色(`--badge`)加黑字**,不是紅色,這是為了符合你的三個色系。
- 連線狀態:「已連線」用水藍(`--blue` 底、`--blueS` 圓點)。「重新連線中」用粉紅(`--pink` 底、`--pinkS` 圓點)。「已離線」用灰(`--surface2` 底、`--muted` 圓點)。三種都有文字標示,不單靠顏色區分。
- 收回的訊息:`--surface2` 底、`--muted` 斜體字。

### 3.2 對比度
- 文字在底色上要達 4.5:1。設計時已避免「灰字壓在白字上」;深色模式的頭像底色刻意調深,讓白字夠清楚。
- 前端實作時,**新增任何顏色組合都要檢查對比度**,尤其是深色模式。

### 3.3 頭像顏色(6 個,由代號計算)
做法:把代號每個字元的編碼依序累加(`h = (h×31 + 編碼) mod 997`),最後 `h mod 6` 選顏色。同一個代號永遠同一個顏色。

| 編號 | 淺色:底色 / 字色 | 深色:底色 / 字色 |
|---|---|---|
| 0 | `#B9A3EC` / `#1A1625` | `#7B62C9` / `#FFFFFF` |
| 1 | `#F4A9C5` / `#1A1625` | `#B64D7C` / `#FFFFFF` |
| 2 | `#8FD0EC` / `#1A1625` | `#2F7FA3` / `#FFFFFF` |
| 3 | `#D7C9F8` / `#1A1625` | `#5D4BA3` / `#FFFFFF` |
| 4 | `#F9CFDF` / `#1A1625` | `#9A456C` / `#FFFFFF` |
| 5 | `#BFE5F5` / `#1A1625` | `#2B6A86` / `#FFFFFF` |

## 4. 字級、間距、圓角

| 項目 | 值 |
|---|---|
| 內文 | 15px,行高 1.5 |
| 次要文字、時間、說明 | 12~13px |
| 標題(欄位標題、人名) | 16px,粗體 |
| 進入畫面大標 | 26px,粗體 |
| 按鈕文字 | 14~16px,主要按鈕粗體 |
| 圓角 | 小按鈕 10~12px、輸入框與按鈕 14~16px、卡片 20~28px、泡泡 18px(靠近說話者的一角 6px)、頭像圓形 |

| 頁面外框 | 電腦版頂部列 60px;左欄 280px;右欄 300px;中欄撐滿(1440 寬時約 860px) |

| 陰影 | 浮動元素(邀請卡片、選單、底部面板)用柔和的紫色陰影;一般卡片不加陰影 |

## 5. 版面

### 5.1 電腦版(三欄,依你的指定)

```
┌──────────────────────────────────────────────────────────────┐
│ 匿名聊天室        [已連線] [語言] [深色] [離開]               │
├──────────────┬─────────────────────────────┬─────────────────┤
│ 線上 12 人    │ 目前的對話                    │ 對話  私聊 3/5   │
│ (左欄 280)    │ (中欄,撐滿)                  │ (右欄 300)       │
│              │                             │                  │
│ 頭像 代號     │  訊息列表                     │ 公開聊天室       │
│ 頭像 代號     │                             │ 小美      ●3     │
│ ...          │ ┌─────────────────────┐     │ 阿強             │
│              │ │ 📷 輸入訊息… 0/500  送出 │   │ 小傑(離線中)    │
│              │ └─────────────────────┘     │ 小華 等待回應…   │
└──────────────┴─────────────────────────────┴─────────────────┘
```
- **左欄「線上」**:標題加人數標籤;每人一列(頭像、代號)。自己那一列標「你」,沒有選項。已有私聊的人標「私聊中」,冷卻中的人標「冷卻中」。
- **中欄**:公開聊天室頂部是 `#` 圖示、名稱、「12 人在線 · 最近 100 則訊息」。私聊頂部是頭像、對方代號、對方狀態、「結束私聊」鈕。
- **右欄「對話」**:標題旁顯示「私聊 N / 5」。第一列固定是公開聊天室;私聊列顯示頭像、代號、最後一則預覽、時間、未讀數。選中的列用 `--lav` 底。邀請中的列顯示「等待回應…」加小的「取消邀請」鈕。

### 5.2 手機版(一次一個畫面)
- **頂部列**:logo 與標題、連線狀態標籤、「⋯」選單鈕(展開後有:語言、深色模式、離開)。
- **底部三個分頁**:公開、私聊、線上。目前所在的分頁用 `--lav` 底;「私聊」分頁在有未讀時右上角顯示粉紅數字標籤。
- **私聊視窗**:沒有底部分頁;頂部左邊是「←」返回私聊清單,接著頭像、代號、在線狀態,右邊「結束私聊」。
- **點線上名單的人**:從畫面底部升起一個面板(頭像加代號、「邀請私聊」、「取消」),背景變暗。
- 輸入區固定在畫面下方。實作時要處理手機鍵盤彈出,輸入區跟著上移、不被擋住。

## 6. 元件規格

### 6.1 訊息
- **泡泡**:自己的 `--own`、對方的 `--peer`,文字 `--text`。自己靠右(右下角尖 6px)、對方靠左(左上角尖 6px)。
- **泡泡最大寬度**:電腦中欄的 62%,手機 78%。
- **分組**:同一個人連續送的訊息,只有第一則顯示頭像和代號(自己的訊息不顯示代號);後面的訊息左側留出頭像寬度的空位。
- **時間**:每則泡泡旁邊,12px(手機 11px),用使用者自己的時區。
- **日期分隔線**:兩條細線夾著「10月13日」這類文字,跨日時插入。
- **系統提示**:置中的圓角膠囊,`--surface2` 底、`--muted` 字,例如「Anna 進來了」「小玲 離開了」「你和小美的私聊開始了」「小美 離線中」。系統提示的文字由多語言檔案決定(見 `architecture.md` 5.3)。
- **照片**:縮圖 200×132(手機 190×126),圓角 13px,泡泡內縮 5px;游標顯示放大鏡。照片可附文字,文字在照片下方。
- **收回**:自己的訊息在滑鼠移上去(電腦)時,泡泡旁出現小的「收回」按鈕(附回復圖示)。手機版用長按顯示。按下後先跳確認(見 6.6)。收回後泡泡變成灰色斜體「此訊息已收回」。
- **新訊息提示**:使用者往上捲看舊訊息時,新訊息進來不強制捲動,改在列表底部顯示膠囊按鈕「↓ 有新訊息」(`--lavS` 底)。

### 6.2 輸入區
- 一列:傳照片鈕(46×46,`--blue` 底)、輸入框(圓角 16px、`--surface2` 底,右側顯示字數 `n/500`)、送出鈕(46 高)。
- 字數**一直顯示**,電腦和手機都是。超過 500 字時字數變成 `--errText` 粗體,送出鈕停用(`--surface2` 底、`--muted` 字、游標禁止)。
- 電腦版輸入框下方有一行小字「Enter 送出 · Shift+Enter 換行」。手機版沒有這行,Enter 是換行。
- 照片預覽列(選了照片之後出現在輸入框上方):52×52 縮圖、檔名與壓縮後大小、進度條與「上傳中 62%」、右側 ✕ 取消。
- 各種輸入區狀態見「各種狀態與提示」畫板:超過字數、送太快(「請稍等 N 秒」)、重複內容、私聊已結束(輸入停用並出現「關閉」鈕)。

### 6.3 邀請
- **收到邀請的卡片**:電腦版在畫面上方中間(寬 460),手機版在頂部列下方左右各留 12px。內容:頭像、「小明邀請你私聊」、「還有 N 個邀請在等你」、「拒絕」(次要按鈕)與「接受」(`--lavS` 主要按鈕)。邊框 `--lavS`。不遮住全畫面、不搶走輸入框焦點。
- **別的分頁時**:瀏覽器分頁標題變成「(1) 有新邀請」。沒有聲音。
- **邀請者那邊**:在對話清單看到「等待小美回應…」列與「取消邀請」。結果以提示條或訊息顯示:
  - 被拒絕:「小美拒絕了你的邀請 · 30 分鐘後才能再邀請這個人」(粉紅)。
  - 逾時:「小華目前正在忙 · 你可以稍後再邀請」(水藍)。
  - 冷卻中:該人的選單裡「邀請私聊」停用,旁邊顯示剩餘時間(例如「29:12 後可再邀請」)。
  - 已有私聊:選單裡改成「前往私聊」。
  - 邀請太頻繁:「請稍後再邀請」。
- **點線上名單的人**:電腦版在那一列旁邊浮出小選單(代號加「邀請私聊」鈕,寬 176);手機版是底部面板。

### 6.4 照片放大
- 整個畫面蓋上暗色背景(約 82% 不透明),照片置中放大(電腦版最大 800×540),右上角圓形 ✕ 鈕,照片下方一行說明(寄件者、時間、「點背景、按 ✕ 或 Esc 關閉」)。
- 點背景、✕、Esc 都能關閉。手機可兩指縮放。載入大圖時先顯示縮圖加轉圈。
- 不做下載按鈕、不做左右切換。

### 6.5 頂部列(電腦版)
- 左:logo(薰衣草方塊加聊天圖示)與「匿名聊天室」。
- 右:連線狀態標籤、語言選單(地球圖示加目前語言加下箭頭)、深色切換(淺色時顯示月亮、深色時顯示太陽)、「離開」鈕(`--pink` 底、`--pinkS` 邊框)。

### 6.6 確認視窗
- **離開**:置中卡片(寬 440),圖示、「離開聊天室?」、「離開後,你的所有私聊都會結束,代號也會釋放給別人使用。確定嗎?」、「取消」與「確定離開」(`--pinkS` 底)。背景暗色。
- **收回訊息**:「收回這則訊息?」「收回後所有人都看不到,也不能復原。」按鈕「取消」「收回」。
- **結束私聊**:「結束和小美的私聊?」「結束後,這個私聊的訊息和照片都會刪除。」按鈕「取消」「結束私聊」。

### 6.7 進入畫面
- 置中卡片(寬 480):logo、「匿名聊天室」、一行說明「不用註冊、不用登入。取一個代號就能進來聊天。」。
- 「你的代號」輸入框加字數 `n/20`;預先填好上次的代號與語言。
- 代號重複時,輸入框邊框變 `--pinkS`,下方顯示「這個代號已被使用,請換一個」(帶圖示)。正常時顯示輔助說明「1 到 20 個字,可以用任何文字。已幫你填好上次用的代號。」。
- 「介面語言」是六顆按鈕(3×2 排列):繁體中文、English、日本語、한국어、Español、Français。選中的用 `--lav` 底、`--lavS` 邊框、粗體;每顆按鈕有 `aria-pressed`。
- 「進入聊天室」是整列寬的主要按鈕(`--lavS`),右側有箭頭。
- 右上角有深色切換。

### 6.8 載入中與空狀態
- 剛進入、重新連線時,對話區顯示灰色骨架泡泡。
- 公開聊天室沒人說話:「還沒有人說話 · 你可以先打聲招呼」。沒有私聊:「還沒有私聊 · 在線上名單點一個人,按『邀請私聊』」。

### 6.9 私聊結束的提示
私聊被結束時,提示留在私聊視窗裡,輸入框停用,使用者按「關閉」才移除這個視窗。文字:
- 「小美已結束私聊」
- 「小美已離開,私聊結束」
- 「小美離線超過 30 分鐘,私聊已結束」
- 「小明取消了邀請」(邀請階段)

## 7. 設計稿與正式前端的差別(要注意)

| 項目 | 設計稿 | 正式前端要做 |
|---|---|---|
| 照片 | 用一張手繪的海邊示意圖 | 顯示使用者真正上傳的照片(縮圖,點開看大圖) |
| 按鈕行為 | 全部是靜態的 | 照 `architecture.md` 第 6、7 節的行為與資料流 |
| 文字 | 直接寫死繁體中文 | **全部走多語言檔案**(六種語言),畫面只引用文字代號 |
| 顏色 | 直接寫在每個元素上 | 集中在 `src/styles/tokens.css`,淺色與深色各一組(第 3 節) |
| 時間、人數、名單 | 假資料 | 來自通訊層(`ChatService`)的事件 |
| 連線狀態的「重新連線中」 | 只畫出標籤 | 要有圓點閃動等動態表現(用 CSS 動畫) |
| 手機的長按收回 | 設計稿只畫了電腦版的 hover 按鈕 | 手機版以長按訊息呼出「收回」 |
| 版面尺寸 | 電腦 1440、手機 390 的定寬畫面 | 要做成**可隨視窗伸縮**:電腦版三欄在窄視窗時改成手機版排版(建議 900px 以下切換) |

### 沒有在設計稿裡畫、但前端要處理的
- 平板與中間寬度的排版(以 900px 為分界,上為三欄、下為手機版)。
- 鍵盤操作與焦點樣式(按鈕、輸入框都要看得到焦點框);圖示按鈕都要有 `aria-label`。
- 照片放大畫面的焦點鎖定(按 Esc 關閉,關閉後焦點回到原來的縮圖)。
- 字很多或很長的代號(顯示時截斷成一行並加「…」,完整代號在提示文字裡)。
- 這份設計**沒有做**多語言的版面測試。不同語言的文字長度差很多(例如 Español、Français 比中文長),按鈕與標籤要能自動撐寬或換行,不能被切掉。
